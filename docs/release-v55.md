# v55 店铺优先上传弹窗

发布日期：2026-10-10。网站已发布 v55，插件保持 11.0.4，不需要重新安装。

## 界面变化

- 打开上传弹窗即显示本账户绑定的在线店铺，保留搜索、多选、全选和加载更多。
- 底部只有“上架商品”“补全资质”两个命令，不再先选任务类型后点击确定。
- 单商品与批量使用相同弹窗，可在打开后选择或调整店铺。
- 搜索回车不会发送；顶部关闭和 Escape 不产生任务。

## 权限与流程

沿用 `/api/agents` 的本人绑定店铺和测试/正式分类隔离；没有绑定的在线可接收店铺时两个命令均不可提交。红标过滤、动态离线禁用、同来源店额外确认及离页停止后续发送保持不变。

点击命令后分别发送既有 `product_create` 或 `qualification_upload` 协议；不改服务端业务接口、数据库、店铺绑定、采集或插件执行流程。

## 验证

- 本地完整 `npm run verify` 通过，Linux 候选和最终发布树完整回归通过。
- 拆分上传网页 25 场景通过，覆盖 1440x900 和 390x844 两种视口及两个动作。
- 商品传输、动态红标、共享/个人库网页专项通过；截图检查两个底部按钮可见且无重叠。
- 正式发布期间商品数据库及共享文件摘要一致，线上只读静态资源和动作协议校验通过。
- 未提交真实 Temu 商品或资质，真实店铺联合执行仍由人工测试。
- 两次独立 Agent 请求均遇到 429 限流，未完成独立审查；本轮完成了主 Agent 代码复核、隔离回归和只读线上核验。

插件安装包和源码沿用 v54；插件资质支持范围及限制见 [v54 说明](release-v54.md)。
