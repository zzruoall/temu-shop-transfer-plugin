# 资质与实拍图修复：11.0.10

日期：2026-10-10。网站以生产 v60 为基线，只合入本次修复；当前请求只发布 GitHub 和安装包，不切换线上网站、不修改生产数据。

## 修复内容

- 目标资质清单明确为审核中或通过时优先跳过，不读取其详情，不因名称、来源附件或模板问题重复报错。
- 上传预检只读取缺失项目详情；来源全量采集仍读取所有实际资质正文，保留已有材料。
- 删除仅凭 Small Business 名称推断店铺主体声明的判断。附件按真实模板搬运，接口明确要求声明、人工确认或生成文档时仍不代签。
- 目标对应位置、视角和 SKU 已有图片时跳过；共用模式不同但所有所需 SKU 已有图，也不报模式错误。仅部分 SKU 已有图时不覆盖、不中途切换共用模式。
- 网站从旧资质真实归档图片派生 `livePhotoCompatibility` 诊断，随资质任务下发，不夹带图片字节、不生成伪造视角或 SKU 归属。
- 插件识别历史图片已有归档但分类不足，明确要求来源店升级、刷新后重新采集；证书仍独立处理。独立 `livePhotos` 快照始终优先。
- 商品创建任务不附带资质、独立实拍图或历史图片诊断，保持商品和资质两条流程分离。
- 修正扩展采集闭环测试的来源身份：实拍图必须进入可下发采集包及网站解析结果，不能只验证本地隔离记录存在。
