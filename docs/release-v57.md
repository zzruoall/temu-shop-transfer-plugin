# v57 本人认领店铺视图隔离

2026-10-10 已发布。网站沿用 11.0.4 插件和签名安装包，不需要重新打包。

## 实际调整

- “全部店铺”排除当前账户本人认领的店铺，先排除再搜索、筛选和分页，避免空页或总数虚高。
- “我的店铺”保留本人店铺，包括离线且没有心跳记录的店铺；认领后进入本人列表，解除后回到全部列表。
- 在线、离线计数随当前标签切换。默认和 `view=all` 完整目录保持兼容，投递目标、绑定、权限以及正式/测试分类不变。
- 服务端仅在 `view=online` 分页响应提供本分类完整 `unclaimableStoreIds` 快照。另一窗口认领后，即使本人搜索或分页不显示该店，也撤销失效勾选，保留其他待认领的跨页选择。快照只用于选择展示，不代替服务端授权。
- 沿用 v56 删除的两段弹窗说明；不可投递时文案改为“暂无可接收当前任务的在线店铺。”，避免误报店铺全部离线。

## 验证

本机和实际 Linux 发布树完整 `npm run verify` 通过。新增 HTTP 隔离测试覆盖两账户、分页、筛选、认领释放、发送目标和分类边界；离线浏览器测试覆盖桌面及手机、标签计数、认领释放，以及另一窗口认领且本人搜索排除的 SSE 场景。拆分上传网页 25 场景通过，测试不接触真实平台。

独立对抗性审查发现跨页勾选残留，已修复并复核；旧插件测试改用实际多选框，版本 smoke 执行实际纯判定函数，而不是仅匹配源码字符串。

线上 7 个现有账户只读检查通过，实际目录及权限入口保持可读。维护切换前后全库和共享文件摘要一致；仅保留 v56/v57 发布目录与对应备份。未提交真实商品或资质，也未改变认领或账号数据。

## 限制

截图中的 11.0.3 在线插件仍不能接收新的拆分任务。前端及服务端最低门槛均为 11.0.4，需更新插件并刷新对应店铺商品列表页，不能通过放宽版本门槛解决。

完整已认领 ID 快照随本分类店铺数量线性增长。传输链路和真实平台创建、资质审核结果仍需联合测试；只读检查不代表真实提交验证。
